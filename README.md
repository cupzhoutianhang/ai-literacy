# 人工智能通识

面向大一碳储科学与工程、石油工程专业本科生的 AI 大模型通识课课件, 共 11 讲, 每讲 50 页, PDF 格式。

- **主讲**: 周天航
- **单位**: 中国石油大学 (北京) 未来能源学院 · 重质油全国重点实验室
- **时间**: 2026 年秋季学期

课程从"大模型是什么"讲起, 依次讲清 Prompt、RAG、Function Call、MCP、Agent、上下文工程、微调这七种能力, 再讲怎样根据需求选能力、怎样把选好的方案沉淀成可复用的工程体系。每一讲都配有能源与工艺现场的例子 (装置数据异常解释、报告写作、安全规程问答、文献综述等), 零基础起步, 不需要编程经验。

## 每讲的结构

- **开场**: 回顾上一讲, 用一个具体情境引出本讲问题, 给出知识 / 能力 / 素养三方面的学习目标
- **四到五个部分**: 概念讲解、示意图、化工场景案例, 穿插 5 ~ 6 个课堂互动 (投票、判断题、小组讨论、现场演示)
- **总结**: 一张总结图、随堂快测 (附答案)、课后任务与拓展阅读、下讲预告

课件中提到的在线工具和文档, 均选用国内网络可以直接访问的链接 (DeepSeek、阿里云百炼、智谱开放平台、hf-mirror 等), 在 PDF 中点击即可打开。

## 使用建议

- 按讲次顺序学习效果最好: 第二讲的关键词会贯穿后面所有讲; 第十讲需要前九讲的基础。
- 只想快速了解某个能力, 可以直接看对应讲次的"总结"与"随堂快测"几页。
- 课件中的价格、显存、耗时等数字大多标注为"示意", 用于说明数量级; 各平台的实际价格与功能以其官方文档为准。
