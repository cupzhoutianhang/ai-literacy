# A03 · 设计只读工具调用并计算泵功率

根据模拟仪表数据安排工具调用顺序，完成压差、流量与液压功率计算。

## 要完成的工作

1. 把 sensors.csv 和 tools.md 交给豆包工作，生成工具调用方案并计算结果。
2. 泵压升 = 出口压力 - 入口压力；液压功率 W = 压升 Pa × 流量 m³/s，不引入效率修正。delta_p_kpa 字段表示泵压升。
3. 计划按 read_sensor → calculate_delta_p → calculate_power 排列，只做只读演示，不控制设备。
4. 至少手算一组数据核对单位，提交两台泵的结果。
