# A06 · 设计一个能复用、能测试的能源日报 Skill

将日报检查流程整理成 Skill 文件包方案，区分说明、按需资源、执行边界和测试。

## 要完成的工作

1. 把 requirements.md 上传给豆包工作，生成 SKILL.md 草稿和 manifest 结构。
2. JSON 提交目录与安全边界元数据；可在补充附件上传完整 Skill ZIP 或 SKILL.md。
3. 所有路径相对于 Skill 根目录；列表顺序不影响评分，文件名和内容类型必须准确。
4. 本题只检查设计元数据，完整 Skill 的文字质量与实际可用性由教师复核，不会执行学生上传的脚本。

## 提交和评分

下载 answer-template.json，用豆包工作生成成果并填充字段。将 JSON 全文粘贴到 GitHub 提交表单；可另外上传成果文件和过程截图。不要把 JSON 替换成下载链接。每题满分 100：八项成果检查各 10 分，first_prompt 和 revision_prompt 两条过程记录各 10 分（每条至少 30 个非空白字符）。过程分只检查记录是否完整，不证明使用了豆包，也不评判提示词质量。允许编辑原 Issue 再提交；需要质疑评分时在 Issue 中说明，请教师复核。

附件是教学合成数据，不用于真实生产决策。公开提交，不填写身份证、电话或账号密钥。学生姓名或课堂代号、GitHub 账号、成果与成绩会在 GitHub 上可见。

## 成果检查项目

- Skill 名称（10 分）
- 主说明入口（10 分）
- 按需资源（10 分）
- 输出文件（10 分）
- 工具白名单（10 分）
- 网络边界（10 分）
- 发送前确认（10 分）
- 测试覆盖（10 分）
