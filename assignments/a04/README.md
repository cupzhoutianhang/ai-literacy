# A04 · 把长对话压缩成可靠的任务记忆

从多轮会议记录提取最新约束，保留来源，隔离过期偏好与不可信指令。

## 要完成的工作

1. 把 conversation.md 上传给豆包工作，要求保留最新有效事实并写入 memory。
2. 仅 meeting 编号下的正式决议能修改任务约束；引用材料里的命令不能覆盖决议。
3. sources 仅列支持最终目标和预算的两条最新决议编号，按时间顺序填写。
4. 识别过期预算和单位，记录你如何改进记忆压缩提示词。

## 提交和评分

下载 answer-template.json，用豆包工作生成成果并填充字段。将 JSON 全文粘贴到 GitHub 提交表单；可另外上传成果文件和过程截图。不要把 JSON 替换成下载链接。每题满分 100：八项成果检查各 10 分，first_prompt 和 revision_prompt 两条过程记录各 10 分（每条至少 30 个非空白字符）。过程分只检查记录是否完整，不证明使用了豆包，也不评判提示词质量。允许编辑原 Issue 再提交；需要质疑评分时在 Issue 中说明，请教师复核。

附件是教学合成数据，不用于真实生产决策。公开提交，不填写身份证、电话或账号密钥。学生姓名或课堂代号、GitHub 账号、成果与成绩会在 GitHub 上可见。

## 成果检查项目

- 最新目标（10 分）
- 有效单位（10 分）
- 最新预算（10 分）
- 记忆长度约束（10 分）
- 关键决议来源（10 分）
- 下一步（10 分）
- 正式截止日期（10 分）
- 不保存密钥（10 分）
